# Docs Index

Entry points: [README.md](../README.md) (English), [LEIAME.md](../LEIAME.md)
(Portuguese). Normative rule and system contracts live in
[`specs/`](../specs/); this directory records direction, intent, and process.

- [`plans/`](plans/) — working process docs: implementation plans
  (`PLAN-01..03`, complete), viability review (`REVIEW-01`, frozen
  historical record), traceability audit (`AUDIT-01`, living re-entry
  log), and the field-test intake (`FOLLOWUP-01`, open).
- [`pilots/`](pilots/) — as-received field pilot reports backing the
  calibration specs; kept verbatim (language as written, not curated).
- [`_origem/`](_origem/) — frozen archive of the founding Portuguese
  docs. Reconciled into plans; never edited in place.
- [`_rulesHackathon/`](_rulesHackathon/) — out of scope: hackathon
  event rules for deadline/disclosure reference only, never project
  requirements.
